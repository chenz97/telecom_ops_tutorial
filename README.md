# 运营商网络运维全流程教程

面向具有计算机专业背景、希望从通信基础学习运营商网络的读者。课程沿用户服务路径解释网络结构，再讲解从规划、建设和开通，到监控、故障、变更以及迁移退网的完整工作流程。

## 开始阅读

用浏览器打开 index.html，即可阅读整套课程。页面提供分组目录、全文关键词搜索、学习进度和字号调整。练习答案可点击展开。点击“打印 / 保存 PDF”，可以通过浏览器生成适合纸面阅读的版本。

course/tutorial.md 保存完整 Markdown 正文，适合在编辑器中阅读、摘录或继续编写。分享 HTML 版时，将教程包完整解压，保留 index.html、assets 和 course 的相对位置。

## 标注与笔记

按住鼠标并拖动，选中同一章节中的正文，再通过浮动工具条选择标注方式。点击“下划线”可添加直线，点击“波浪线”可添加波浪下划线；同一选区的两种线条可以互相切换。“强调”为文字添加背景色，“注释”用于记录理解和疑问，二者可以与下划线一起使用。使用键盘选择文字后，按 Tab 进入标注工具条，再按 Enter 执行操作。手机上选择文字后，工具条显示在屏幕底部。

点击带标注的文字，会显示同一个操作横条。已经应用的样式按钮显示为选中状态，点击可以取消。多个不同范围的标注重叠时，横条默认操作较短的选区，可通过范围选择切换到其他摘录。有注释时，屏幕下方展示注释内容，提供编辑和删除操作。每段选中文字保留一条注释，再次添加时进入已有注释的编辑。页面上方的“我的标注”集中展示所有摘录，并提供回到原文、编辑注释和删除操作。标注保存在当前浏览器，刷新后自动恢复；清除学习进度会保留标注。

在“我的标注”中点击“导出标注”，可以将笔记保存为 JSON 文件。换用其他浏览器或设备时，打开同一教程，再点击“导入标注”选择这个文件。导入会合并记录，重复导入同一文件会保留一份记录，同一选区已有的线条样式与注释保留当前内容。打印或保存 PDF 时，正文保留标注，个人注释集中附在课程末尾。

## 学习路径

课程包含 24 个章节，建议分六次学习：

1. 01—03：理解信息传递、质量指标和网络全景。
2. 04—07：沿家庭宽带、移动通信和企业服务看懂网络路径。
3. 08—11：理解组织分工，以及规划、交付与资源管理。
4. 12—15：学习监控、故障恢复、复盘与变更。
5. 16—20：理解增长与投诉的处理，再学习安全、应急及退网。
6. 21—23：完成综合案例，使用术语与流程速查继续学习。

第 00 章提供详细学习安排。顺序学习时，每章先阅读场景与原理，再完成自测。按工作问题查阅时，可以搜索“开通”“光纤”“回退”等关键词。

## 内容与资料

教程包含四个综合案例，覆盖医院专线全生命周期、光缆中断、移动网络晚间拥塞和核心网软件升级回退。案例贯穿服务影响、资源依赖、责任协作及恢复验证。课程还提供工作记录示例、术语索引和十道复习题。

课程先沿一次数据交付解释通信，再沿服务生命周期解释运维。每节围绕一个问题逐步引入原理、例子和检查依据，包含宽带上线与移动会话的连续过程。排队时延、光功率预算和容量增长等数值案例给出公式、代入与结果，并说明结果怎样影响方案选择。全书有 38 组可展开练习，参考答案先给出结论，再说明推理、计算和验证方法。

第 23 章汇集 30 项来自标准组织与行业组织的一手参考资料，并提供具体问题与阅读入口，便于继续学习。

## 源码维护

在项目根目录执行 python3 scripts/build.py 更新 HTML；执行 python3 scripts/check.py 检查章节、链接和资源；执行 python3 scripts/browser_check.py 检查浏览器交互及版面；执行 python3 scripts/annotation_check.py 检查标注交互、保存与导入导出；执行 python3 scripts/package.py 重新生成教程压缩包。

构建依赖见 requirements.txt。浏览器验证需要 Playwright 的 Chromium。项目目标、架构和设计记录保存在 docs。当前教材重点层级与独立审阅记录见 docs/execution/tutorial-emphasis.md；此前表达修订见 tutorial-expression.md，早期建设、技术扩展和叙述重组分别记录在该目录的 tutorial.md、tutorial-depth.md 和 tutorial-coherence.md。个人标注功能记录见 annotations.md，工具条与底部注释交互记录见 annotation-interaction.md。

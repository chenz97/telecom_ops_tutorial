# 阅读器设计

## 内容模型

教材正文保存在 course/tutorial.md。二级标题格式为两位章节号、间隔点和标题，形成 00—23 的稳定章节标识。三级标题组织章内主题；原生 details 元素承载练习答案；HTML 流程图同时包含可访问的文字描述。生成器使用 markdown-it-py 开启表格解析和受控本地 HTML。

## 教学内容组织

正文按读者需要解决的问题安排知识出现的顺序。通信部分沿一份数据的交付过程逐步解释信号与封装，再连接到状态与资源；运维部分沿一项服务从需求到退出的阶段展开，前一阶段的结果成为后一阶段的输入。段落在同一问题内建立条件、机制和结果，术语在参与解释时定义。比较表和流程表回顾已经说明的关系，参考索引支持集中查阅。

计算用于解释实际判断，按公式、代入、结果和解读展开，明确单位和计算条件。方案中的阈值说明选择依据，标准规定的数值附对应来源；流程检查点写明通过结果与失败后的调查方向。练习检验读者能否依据已讲过的机制推理，综合案例将路径、证据与行动接成完整过程。内容重组保留章节身份，独立读者仅阅读教材检查自洽性与可理解性。

核心机制交代设计约束、参与者交互和状态变化；段落关系依照主题选择推导、时间推进、比较或整体分解。独立阅读验收记录读者对机制的实际复述，以及改变一个条件后的预测和依据，并根据无法继续推理的位置补齐解释。

正文区分关键结论、术语定义和支撑说明。决定解释或行动的主导机制使用独立加粗段落，具体检查规则在段内选择性加粗，例子与辅助条件保持正常字重。每条结论在相邻正文中由原因、数值后果或具体场景支持。核心结论直接融入相应主题，章内避免重复摘要和普遍加粗。

生成器将仅含一个纯文字 strong 元素的段落标记为 key-point。网页以较强字重、左侧线条和浅色背景突出这类结论，学习目标保留原有较小字号；手机按正文宽度自然换行。打印保留字重和线条，结论块尽量与后续解释同页。源稿使用普通 Markdown 加粗语义，浏览器标注继续保留原有段落和 strong 结构。

## 导航与搜索

页面显示全部章节，按学习阶段组织目录。搜索对章节标题和正文进行不区分英文大小写的连续关键词匹配，并隐藏未匹配章节；显示匹配数量和空结果提示。点击隐藏章节的导航链接会恢复全部章节后跳转。桌面目录固定在左侧，窄屏使用可展开目录，点击章节后收起。

## 阅读状态

学习完成标识以稳定章节号集合保存到本地存储 telecom-course-progress-v1，读取时只接受当前教材的有效标识。非法数据重置为未完成；存储不可用时仍能在当前页面标记与阅读，并显示当前保存状态。字号另存于 telecom-course-font-v1。清除学习进度只清理当前教材的完成标识。

## 个人标注

选区由浏览器 [Selection](https://developer.mozilla.org/en-US/docs/Web/API/Selection) 与 [Range](https://developer.mozilla.org/en-US/docs/Web/API/Range) 接口取得。每条记录保存章节标识、正文文本的起止位置、摘录和前后各最多 48 个字符的上下文，另存标注类型、注释、唯一标识与创建时间。位置以 JavaScript 字符串的 UTF-16 单元计数，与浏览器文本节点和 Range 偏移一致。存储键为 telecom-course-annotations-v1，JSON 外层版本号为 1，记录集合字段为 annotations。

位置恢复采用文本位置与摘录上下文组合，参考 [W3C Web Annotation 的 Text Quote Selector](https://www.w3.org/TR/annotation-model/#text-quote-selector)。首先验证旧位置上的摘录和上下文；随后搜索摘录，接受唯一上下文匹配或唯一摘录位置。多个位置无法区分时，记录在列表中保留为待确认状态。恢复的位置单独保存在内存中，保留原始记录用于导出。

渲染时先移除本功能生成的 span 包裹，再遍历正文文本节点。按相交标注的起止位置拆分节点，为每段文字附上覆盖它的标注标识和类型样式。原有段落、链接和加粗结构保持完整，正文 textContent 保持一致。多种类型和多条同类记录可以重叠，删除后根据剩余区间重新渲染。搜索索引由 app.js 在标注脚本运行前生成。

指针在正文按下时记录手势状态，期间隐藏操作面板并暂停选区检查，保持原生 Range。移动超过 4 像素或释放时存在选区时，随后生成的点击事件按拖选处理；释放或取消后再更新横条。被动选区检查与滚动只关闭界面，显式关闭或执行标注时才清理原生选区。选区工具条在桌面跟随选区，在手机固定于屏幕底部；键盘选择后通过 Tab 进入操作。点击正文标注使用与选区相同的横条，样式按钮显示当前选区的应用状态，再次点击切换该样式。下划线类型包括 underline 与 wave，分别采用直线和 CSS wavy 样式；同一选区的两种下划线互相切换，并可与强调和注释叠加。读取与导入时，同一选区的多条线条记录按创建时间保留最新样式。有注释时同时打开非模态底部面板，提供编辑和删除；手机横条位于面板上方，桌面横条保持在原文附近并避开面板。注释编辑使用固定于底部的原生 dialog，全部标注列表也使用原生 dialog，两者提供焦点约束与 Escape 关闭。不同选区重叠时默认选择最短选区，横条以字数和摘录片段提供范围切换；底部保留覆盖点击位置的注释，编辑时使用该注释自身的完整范围。底部面板支持正常 Tab 顺序和文本复制。点击正文其他位置或按 Escape 关闭横条与预览。回到原文时清空搜索、展开所需答案并定位标注。点击链接中的标注保留原有链接行为，记录可从“我的标注”管理。用户输入通过 textContent 写入页面。选区错误和保存失败同时更新首页状态与屏幕底部可见提示，保存失败时引导进入“我的标注”导出。

每次保存只重绘受影响章节。单个选区最多 5000 个字符，新建注释最多 2000 个字符，同一章节和恢复后选区保留一条注释；再次添加进入已有内容编辑。旧数据的重复注释按创建时间合并不同文字，保持一条记录，并允许编辑完整的合并内容。总量最多 2000 条。JSON 导入先验证版本、字段和课程章节，再合并；相同内容的记录去重，同一选区的线条样式与注释导入时保留当前内容，文件内部的旧重复注释先合并；同一标识与摘录重复导入时保留当前注释，其他唯一标识冲突时为新增记录分配新标识。合并并归一化后检查容量，并按最终记录计算新增数量。读取文件上限为 20 MiB。验证失败保持当前记录，存储不可用时保留本次页面状态并提供导出。学习进度的清除操作保持个人标注。

## 离线与打印

index.html 使用相对路径加载本地 CSS 和 JavaScript，无运行时外部依赖。关闭脚本后正文、目录和原生答案展开仍可使用。打印样式显示全部章节，隐藏阅读工具；打印前展开答案，打印后恢复此前关闭的状态。打印时保留普通下划线、波浪下划线和强调，将注释摘录和内容附在课程末尾。每章从新页开始，表头重复，表格行和短答案尽量避免分页拆分。

## 维护约定

正文变更后执行 python3 scripts/build.py，再运行结构检查和与变更相关的浏览器验证。生成文件不手工修改。新增章节时同步生成器目录分组和结构检查中的课程范围，并检查所有章间导航。

# 拖动选区恢复与波浪下划线

## 目标

正文支持按下鼠标后拖动选中文字，包括在已有标注上开始、慢速拖动及跨行选择。选区操作与点击已有标注分别处理，拖动过程保留浏览器原生选区。阅读横条增加波浪下划线，可保存、切换和移除，并支持导入导出与打印。

## 定位与修复

复现时先按下鼠标并停顿 250 毫秒，旧脚本会在选区折叠时调用 removeAllRanges，rangeCount 变为 0，随后拖动无法恢复锚点。修复通过指针手势状态暂停检查，同时将界面关闭与选区清理分别处理。滚动期间也保持拖选原生状态，已有标注的拖动不会触发查看点击。

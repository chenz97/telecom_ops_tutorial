# 标注横条与底部注释交互

## 目标与范围

点击正文已有标注后，在原文附近显示与选区共用的操作横条。横条可以切换下划线与强调，并进入注释操作。有注释时，屏幕下方展示该注释及编辑、删除入口。每个正文选区保留一条注释，“我的标注”继续承担全部记录查阅与文件管理。

## 实施计划

首先统一选区与点击标注的上下文，处理横条状态和关闭行为；随后实现底部注释面板与编辑返回，并在新建、读取和导入时统一单条注释规则。最后更新浏览器检查，验证重叠样式、持久化、旧数据兼容与手机布局，进行独立读者复核并重新打包。

## 技术决定

标注对象以章节与恢复后的选区位置识别，原有独立样式记录继续保存。点击重叠区默认操作最短选区；不同范围提供摘录选择，底部同时显示覆盖点击位置的注释，编辑使用该注释的完整范围。横条中的下划线与强调提供当前状态和切换操作。底部注释面板采用非模态对话区域，保持正文与横条可操作；编辑使用原生 dialog 并固定在屏幕下方。

同一选区的新注释进入编辑已有内容。旧数据中的重复注释合并为一条，按创建时间保留各段不同的文字内容。导入保持当前注释，并合并文件内部的旧重复记录。浏览器缓存键与导出版本继续沿用原有格式。

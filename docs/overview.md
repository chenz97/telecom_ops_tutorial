# 项目概述

本项目是一套面向计算机专业人士的运营商网络运维入门课程。通过用户服务路径和工作场景解释通信基础、网络结构及运维全生命周期，使没有通信背景的读者能够形成连贯的知识体系。

课程以浏览器阅读为主要方式，同时提供 Markdown 正文。通信部分沿一份数据的交付过程解释物理信号、协议交互与业务状态；运维部分沿一项服务从需求到退出的阶段展开，使每个阶段的结果成为后续判断的依据。概念和计算在读者需要解释现象时出现，随后用于交付、观测与恢复。学习重点包括原理、实现过程和运维流程，以及跨专业协作和证据判断。课程覆盖固定与移动网络，并延伸到企业服务和承载它们的基础设施。

读者可以顺序完成整套课程，也可以根据开通、故障、变更等任务查阅相关章节。课程在本地离线运行，参考材料链接用于进一步学习。技术讲解使用代表性协议过程、简单公式与数值案例；实际设备操作可在此基础上结合厂家手册学习。

课程已完成 24 章，配有四个综合案例、逐章练习和术语与流程速查。一手参考资料用于进一步学习，独立读者审阅与浏览器验证保证内容和阅读体验能够完整交付。

读者可在正文中添加普通或波浪下划线，也可突出重点并记录注释。标注列表帮助读者回到原文继续学习。个人笔记随浏览器本地保存，也可导出后在其他设备导入；打印时附带个人注释。
